# 아티스트하우스 HTML 리포트 생성기

`printReport.m`의 예중/예고 입시반 리포트 생성 흐름을 브라우저용으로 옮긴 정적 HTML 버전입니다.

## 사용

1. `index.html`을 브라우저에서 엽니다.
2. `템플릿 다운로드`로 받은 `inputTemplate.xlsx` 형식에 맞춰 데이터를 작성합니다.
3. `평가서 생성` 버튼으로 작성한 엑셀 파일을 선택합니다.
4. 미리보기가 생성되면 `PDF 저장/인쇄`를 눌러 브라우저 인쇄 화면에서 PDF로 저장합니다.

## 구현 기준

- `성적` 컬럼이 있으면 MATLAB 코드와 같이 대학 입시용 템플릿으로 판단해 오류를 표시합니다.
- 마지막 행의 `이름`, `학교`, `학년`, `종합평가`, 지원 가능 학교 정보를 리포트에 반영합니다.
- 첫 행과 마지막 행의 `리포트시점` 차이로 `N개월 차`를 계산합니다.
- `실기/내신` 막대그래프, 실기 요소 오각형 그래프, 월별 실기요소 변화 그래프를 Canvas로 생성합니다.
- `.xlsx` 읽기는 브라우저에서 SheetJS CDN을 사용합니다. 오프라인 환경에서는 CDN 파일을 내려받아 `index.html`의 스크립트 경로를 로컬 파일로 바꾸면 됩니다.
